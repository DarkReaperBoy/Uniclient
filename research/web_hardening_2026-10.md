## 1. Architecture map (web view)

```
user browser
  └─ https://darkreaperboy.github.io/Uniclient/  (gh-pages branch, orphan)
       ├─ index.html     6,962 B   boot overlay + self-updating shell (JS)
       ├─ wasm_exec.js  16,992 B   Go runtime glue (copied from $GOROOT/lib)
       ├─ uniclient.wasm 88,455,158 B  the whole app (gui+engine+cores)
       └─ .nojekyll
             built ONLY at CI time (release.yml web job, needs [test]);
             main branch never contains JS/HTML (§1.4).

shell flow (index.html):
  boot() → stream(wasm_exec.js, no-cache) → if ETag changed, inject <script>
         → stream(uniclient.wasm, no-cache) with determinate MB progress bar
         → offline fallback: fetch(force-cache)
         → compareRev(localStorage etags) → "downloaded"/"up to date"/"updated"
         → MutationObserver(body) hides overlay when <canvas> attaches
         → WebAssembly.instantiate(bytes, go.importObject); go.run(instance)
         → resolve/throw ⇒ "Uniclient stopped" + Retry button

Go side (GOOS=js GOARCH=wasm CGO_ENABLED=0 -tags goolm):
  cmd/uniclient/main.go   one binary; flags (UNICLIENT_HOME/-dir/-password)
  bootstrap.Init          engine.Init + core factory (9 platforms) + purge
  gui/                    Gio app (AyuGram 1:1 layout); on js renders into a
                          full-window canvas; explorer/openext via window.open
  engine/                 accounts, events, media, pending, player, vault I/O
  cores/                  9 backends behind cores.Core (~90 methods + StubCore)
  utils/                  vault (Argon2id+AES-GCM), config, session store
  audio/webaudio_js.go    WebAudio in/out (ScriptProcessorNode, getUserMedia)
  wrtc/js.go              pion js API: signaling only, media stubs → ErrUnsupported
  platform quirk files:   engine/dirs_js.go (ensureDir no-op),
                          engine/lock_js.go (no single-instance lock),
                          engine/db_driver_js.go (null SQL driver — no cache),
                          utils/vault_io_js.go (vault in localStorage),
                          cores/bale_ws_js.go (browser WS dial), openext_web.go
```

Web truth table (verified this session, Go 1.27.3):
- **Connectivity from a browser:** raw TCP is impossible in WASM (no
  sockets). Net-stack backends: GitHub + Matrix (fetch/HTTPS) work; Bale
  works (gRPC-Web over WebSocket; calls return ErrNotSupported via
  bale_calls_js.go). Telegram/IRC/XMPP/DeltaChat/TeamSpeak/Mumble dial
  raw TCP ⇒ cannot ever connect on web.
- **Persistence on web:** vault (accounts/credentials/sessions/config)
  → localStorage key "uniclient.vault", AES-GCM encrypted, default
  password "uniclient" (no way to pass -password/env to a wasm argv).
  Cache DB → null driver (every query returns no rows; writes are no-ops)
  ⇒ history/media exist only for the live session.
- **Single instance:** none on web (lock_js no-op) — every tab is its own
  engine instance sharing one vault.
- **Audio:** WebAudio playback + getUserMedia mic capture (voice paths
  reachable through Mumble/TS on native; on web voice is unreachable
  because no TCP/UDP voice backend connects).

## 2. Critical user journeys (web)

J1 **Boot, first visit:** GET / → overlay "Starting…" → determinate progress
   with MB counter → "Starting Uniclient… wasm: 84.2 MB — downloaded" →
   canvas attaches → overlay hides → Gio welcome screen ("Add an account").
J2 **Boot, repeat visit:** same, but ETag match ⇒ "up to date"; 304 handled
   by HTTP cache; no re-download.
J3 **Boot after a deploy:** both wasm_exec.js and wasm rev change ⇒
   "updated" readout; refreshed wasm_exec.js injected over the static copy.
J4 **Add account:** welcome CTA → picker grid (9 cards) → pick backend →
   engine auth state machine drives the form (steps, progress, error).
   Only github/matrix/bale can reach a server; the others fail at dial.
J5 **Chat session:** login → live events populate chat; reload ⇒ empty cache
   (history gone — known web limitation, host-layer caching is doc-fiction).
J6 **Failure/retry:** wasm fetch fails (or offline with nothing cached) ⇒
   "Uniclient stopped" + detail + Retry; retry re-runs boot exactly once
   (double-click safe via `running` flag).
J7 **App exit:** go.run resolves ⇒ "Uniclient exited" + Retry (relaunch).
J8 **Vault continuity:** accounts added survive reload via localStorage;
   two tabs open simultaneously ⇒ each rewrites the whole vault from its
   own stale copy (see R1).

## 3. Risk zones found (candidates for Phase 2, with severity)

- **R1 — data loss: two tabs clobber the vault.** utils/vault.go flush()
  rewrites the ENTIRE vault from in-memory state on every Save; on web
  there is no instance lock (lock_js no-op) and both tabs Save full
  copies ⇒ last writer erases the other tab's accounts/sessions/config.
  Native prevents this with the lock file. Severity: data loss/crash.
- **R2 — leak: startMic failure path.** audio/webaudio_js.go: if
  getUserMedia rejects, failed() closes the frames channel but leaves
  micStop/micDone/micFn/micCh set; a later startMic overwrites them ⇒
  the old cleanup goroutine blocks forever on a never-closed stop chan
  and the old js.Func is never Released. Plus setup/failed js.Funcs are
  never Released at all (every mic start leaks 2 callbacks). Severity:
  leak (grows per denied permission / per voice session).
- **R3 — wrong behavior: mic rate not resampled.** micRate is captured
  from the first buffer but never used; pending samples are sliced into
  48 kHz frames regardless of the actual AudioContext rate (browsers may
  ignore the forced sampleRate — older Safari). Pitch-shifted voice.
  Severity: wrong behavior (conditional on browser).
- **R4 — wrong behavior: web picker offers 6 impossible backends.** The
  picker lists all 9 platforms on GOOS=js; 6 dial raw TCP and can only
  ever show a connection error. §1.10: "if it cannot work yet, hide it".
  Severity: wrong behavior (web-specific §1.10 violation).
- **R5 — no crash surface after boot.** The shell hides the overlay when
  the canvas attaches; if the Go side panics later (or go.run exits
  abnormally), the page sits dead with no console-visible UI state and
  no retry. No window.onerror/unhandledrejection handler exists.
  Severity: degraded UX on the failure path.
- **R6 — MutationObserver accumulation.** Each failed boot leaves its
  observer connected; retries stack observers (all disconnect on first
  canvas — self-healing but sloppy). Severity: cosmetic.
- **R7 — comments contradicting code.** vault_io_js.go claims the path is
  "hashed into the storage key" (it is ignored); db_driver_js.go claims
  an IndexedDB host layer persists the cache (none exists). Misleads the
  next maintainer. Severity: cosmetic/doc (rule 8).
- **R8 — wasm payload is 88.5 MB (20 MB gzipped transfer).** First-visit
  download cost; measured live. Phase 4 baseline recorded here; shell
  streams with progress so UX is honest. Optimization headroom: none
  without feature cuts (single binary by design); a compressed-cache
  (Cache Storage) would avoid re-downloading on deploy-only-JS changes.
  Evaluate in Phase 4 with measurements.
- **R9 — vault on web is encrypted with a fixed default password**
  ("uniclient"; env/flags unreachable in wasm). Ciphertext-at-rest only.
  Documented product behavior (vault password UI is a native-side
  feature); flagged for Phase 6 review, not silently changed.
- **R10 — GatheringCompletePromise (js) returns an immediately-closed
  channel** ⇒ RESOLVED BY AUDIT (Phase 2): every caller relays late ICE
  candidates through OnICECandidate → sendICECandidates (trickle), and
  each caller's native wait is bounded at 5s anyway — shipping SDP
  before gathering completes matches browser-native negotiation. The
  wrtc/js.go comment now documents the contract. Not a bug.

Clean areas verified during recon: release.yml web job ordering (needs
test, then deploys), verify.yml parity, flake.yml hash recipe, scripts/

at every media entry point), bale_calls_js.go honest ErrNotSupported,
