# app_state — State management layer audit

- [ ] [CRITICAL] Power saving flag bit assignments are all wrong — Dart maps `kPowerSavingStickersPanel = 1 << 0` but AyuGram `kAnimations = 1U << 0`; `kPowerSavingStickersChat = 1 << 1` but AyuGram `kStickersPanel = 1U << 1`; `kPowerSavingEmojiPanel = 1 << 3` but AyuGram `kStickersChat = 1U << 2` is missing entirely; `kPowerSavingChatEffects = 1 << 8` but AyuGram `kCalls = 1U << 8`; `kPowerSavingCalls = 1 << 10` but AyuGram `kChatEffects = 1U << 10`; `kPowerSavingAnimations = 1 << 11` is beyond `kAll = (1U<<11)-1` — every power saving toggle will control the wrong feature — `app_state.dart:369-379` ← `AyuGram/ui/power_saving.h:13-25`

- [ ] [CRITICAL] Notification type settings never pushed to engine — `set notifPrivateChats`, `set notifGroups`, `set notifChannels` (lines 2078-2083) only call `_saveWindowPrefs()` but never call `_engine.updateConfig(notifyDms:, notifyGroups:, notifyMentionsOnly:)` despite the engine supporting these fields — toggling these settings has no effect on actual message delivery — `app_state.dart:2078-2083` ← `dart/lib/bridge/engine_service.dart:3893-3951`

- [ ] [MAJOR] `_saveWindowPrefs()` performs synchronous file I/O on the main thread on every single setting change — `File(path).writeAsStringSync(jsonEncode({...}))` with a 200-key JSON object is called in all 100+ setter methods with no debouncing or async dispatch — this blocks the UI thread on every toggle — `app_state.dart:3030` ← `AyuGram/core/core_settings.cpp:1078` (AyuGram uses batched async saves)

- [ ] [MAJOR] `_loadWindowPrefs()` performs synchronous file I/O on the main thread during `initialize()` — `file.readAsStringSync()` deserialising a large JSON blob blocks the Flutter engine's init path — `app_state.dart:2778` ← `AyuGram/core/core_settings.cpp:1175` (AyuGram loads settings during pre-launch, before the UI event loop starts)

- [ ] [MAJOR] `swipeAction` setter does not persist — `set swipeAction(String value)` at line 2031 calls only `notifyListeners()`, missing the `_saveWindowPrefs()` call present in every other setter — swipe action preference is lost on every restart — `app_state.dart:2030-2035` ← `AyuGram/dialogs/dialogs_quick_action.cpp:67` (action is persisted to settings in AyuGram)

- [ ] [MAJOR] `_autoMigrateGhostToGlobal()` modifies `_useGlobalGhostMode` and the ghost settings map without calling `notifyListeners()` — UI widgets reading `useGlobalGhostMode` or `ghostModeSettings` will not update when single-account migration triggers silently on account switch — `app_state.dart:1336-1346` ← `AyuGram/ayu/ayu_settings.cpp:137` (AyuGram notifies all observers via rpl after mutation)
